Seguridad Firebase
Aplicá estas reglas en la consola de Firebase → Firestore → Reglas, para que solo tu app pueda leer y escribir: 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /aromagest/data {
      allow read, write: if request.auth == null
        && request.headers['origin'] ==
        'https://aromagest-d45cb.firebaseapp.com';
    }
  }
}
Esto restringe el acceso únicamente al documento de AromaGest.
